## GPA Calculator Program

### 1. Problem Description
Design a program (Pseudocode only) that takes Course grades ($G$) and Credit hours ($H$) from the user, and calculates the final GPA of the student according to the following formula:
$$\text{GPA} = \frac{\text{Course grades } (G)}{\text{Credit hours } (H)}$$

---

### 2. Problem Analysis
* **Variables Identification:** Course grades ($G$) and credit hours ($H$) are variables that must be received by the user. The result might become a real number because of division/multiplication, so variables must be identified as real numbers (`G`, `H`, `GPA`).
* **Shortcuts:** Use clear shortcuts for all variables (`G`, `H`, `GPA`) to avoid spelling errors and maintain clarity.
* **User Interaction:** The program must be user-friendly, guiding the user to input data by providing clear prompts.
