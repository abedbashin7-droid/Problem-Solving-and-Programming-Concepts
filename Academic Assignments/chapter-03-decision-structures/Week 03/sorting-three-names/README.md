# Assignment: Sorting Three Names in Alphabetical Order

## 1. Problem Analysis
- **Objective:** Design an algorithm to organize three names inputted by the user into alphabetical order using Pseudocode and a Flowchart.
- **Variables:** Declare three string variables (`nam1`, `nam2`, `nam3`).
- **Logic & Approach:** 
  - Using nested `If-Else` conditions is the most efficient way to evaluate all comparative possibilities.
  - The solution handles character comparisons based on standard lexicographical ordering.
