# Assignment: Sorting Three Numbers in Ascending Order

## 1. Problem Analysis
- **Objective:** Design an algorithm to organize three numeric values inputted by the user into ascending order (from smallest to largest) using Pseudocode and a Flowchart.
- **Variables:** Declare three numeric/real/integer variables (`mun1`, `mun2`, `mun3`).
- **Logic & Approach:** 
  - Utilizing nested `If-Else` conditions to evaluate all possible numeric relationship paths using relational operators (`<`, `<=`).
  - Checking numerical values directly avoids the overhead of character ASCII conversions, focusing purely on comparative arithmetic logic.
