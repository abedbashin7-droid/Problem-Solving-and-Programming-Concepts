==================================================
PROGRAM: Month Name Lookup (Select Case Structure)
TYPE: Self-Exercise / Practice Problem
SUBJECT: Problem Solving and Programming Concepts
==================================================

1. PROBLEM STATEMENT:
Design a program that accepts a month number (1-12) from the user and outputs the corresponding month name.
If the number is outside the range 1-12, display "ERROR, Invalid Number".

2. LOGIC ANALYSIS:
- Input: Single integer variable 'mon'.
- Structure: Use 'Select Case' instead of nested 'If' conditions for optimal readability and direct execution flow.
- Default Handling: Output error message for values outside 1-12.

3. PSEUDOCODE:
Step 1: Start
Step 2: Declare Integer mon
Step 3: Display "Enter the month's number : "
Step 4: Input mon
Step 5: Select mon
            case 1:
               Display "January"
            case 2:
               Display "February"
            case 3:
               Display "March"
            case 4:
               Display "April"
            case 5:
               Display "May"
            case 6:
               Display "June"
            case 7:
               Display "July"
            case 8:
               Display "August"
            case 9:
               Display "September"
            case 10:
               Display "October"
            case 11:
               Display "November"
            case 12:
               Display "December"
            case default:
               Display "ERROR, Invalid Number"
        End Select
Step 6: End
