# Problem Solving & Programming Concepts

> Algorithmic logic, structured pseudocode, and flowcharts for foundational computer science concepts.

Documented solutions, assignments, and self-practice exercises developed during my first semester in Computer Science, following ***Starting Out with Programming Logic and Design*** by Tony Gaddis.

---

### 📁 Contents & Topics

- **Academic Assignments**
  - `reverse-two-digit-number` — Arithmetic operations & Modulus (`MOD`)
  - `division-handling-zero` — Input validation & division-by-zero handling
  - `comparing-two-numbers` — Relational comparisons (Max, Min, Equal)
  - `number-checking` — Tri-state logic (Positive, Negative, Zero)
  - `sorting-three-numbers` — Ascending numerical sorting
  - `sorting-three-names` — Alphabetical string comparison
  - `login-system` — Authentication with Boolean logic (`AND`)

- **Quizzes**
  - `GPA Calculator` — Weighted calculations & formula logic

- **Personal Exercises**
  - `month-lookup-select-case` — Multi-way branching using `Select Case`

---

### 🧩 Documentation Flow

Every challenge follows a uniform 3-file structure:
1. **`README.md`**: Problem statement, logical analysis, and an embedded [Mermaid.js](https://mermaid.js.org/) flowchart.
2. **`pseudocode.txt`**: Clean, language-independent pseudocode.
3. **`mermaid.js`**: Raw diagram source code.
